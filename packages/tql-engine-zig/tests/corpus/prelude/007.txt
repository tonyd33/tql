title: `all` is true only when every element satisfies the predicate
grammar: typescript
pending: values

`all` probes for a *violating* element by swapping the inner branch arms
(`branch predicate empty identity`), then negates the result. Its scheme
matches `any`: `Filter a b -> Filter b bool -> Filter a bool`.

--- tql ---
main = . / :class_declaration | all (.body / :method_definition) (.name | text ~ r"^get");

--- source ---
class A { getX() {} getY() {} }
class B { getZ() {} setW() {} }

--- values ---
[true, false]
