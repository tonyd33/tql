title: `all_m` is true only when every element satisfies the predicate
grammar: typescript
asserts: types, values

`all_m` probes for a *violating* element by selecting the inputs whose
predicate is false, then inverts the result. Its scheme matches `any_m`:
`Filter a b -> Filter b Bool -> Filter a Bool`.

--- tql ---
main =
  children | is_kind :class_declaration
  | all_m (.body | children | is_kind :method_definition)
        (.name | arr (\n -> text n ~ r"^get"));

--- source ---
class A { getX() {} getY() {} }
class B { getZ() {} setW() {} }

--- values ---
[true, false]

--- types ---
main : Node -> [Bool]
