title: `all` over an empty source is true
grammar: typescript
pending: values

Vacuous truth, and the dual of PRE-06. No violating element exists, so the
inner probe is false and `all` yields true. A definition with the branch arms
in the wrong order would yield `false` here, so this fixture pins the arm
ordering.

--- tql ---
main =
  children | is_kind :class_declaration
  | all (.body | children | is_kind :method_definition)
        (\m -> [text m.name ~ r"^get"]);

--- source ---
class B {}

--- values ---
[true]
