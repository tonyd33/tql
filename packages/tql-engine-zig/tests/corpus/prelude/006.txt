title: `any` over an empty source is false
grammar: typescript
asserts: types, values

The source yields nothing, so the probe finds no first result.

--- tql ---
main =
  children | is_kind :class_declaration
  | any (.body | children | is_kind :method_definition)
        (.name | lift (\n -> text n ~ r"^get"));

--- source ---
class B {}

--- values ---
[false]

--- types ---
main : Node -> [Bool]
