title: `select` keeps inputs whose predicate holds
grammar: typescript
asserts: types, values

`select p = branch p identity empty`. Unifying `identity : Filter a a` against
the sibling `empty` arm pins the result type, giving
`select : Filter a Bool -> Filter a a`.

--- tql ---
main =
  children | is_kind :class_declaration
  | select (.name | lift (\n -> text n ~ r"^S")) | .name | lift text;
