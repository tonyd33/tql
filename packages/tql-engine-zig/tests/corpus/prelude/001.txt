title: `select` keeps inputs whose predicate holds
grammar: typescript
asserts: types, values

`select p = branch p (arr identity) none`. Unifying `arr identity :
Filter a a` against the sibling `none` arm pins the result type, giving
`select : Filter a Bool -> Filter a a`.

--- tql ---
main =
  children | is_kind :class_declaration
  | select (.name | arr (\n -> text n ~ r"^S")) | .name | arr text;
