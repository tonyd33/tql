title: `any_m` is true when some element satisfies the predicate
grammar: typescript
asserts: types, values

`any_m source predicate = probe (kleisli source (select predicate))`, typed
`Filter a b -> Filter b Bool -> Filter a Bool`.

--- tql ---
main =
  children | is_kind :class_declaration
  | any_m (.body | children | is_kind :method_definition)
        (.name | arr (\n -> text n ~ r"^get"));

--- source ---
class A { getX() {} setY() {} }
class B { setZ() {} }

--- values ---
[true, false]

--- types ---
main : Node -> [Bool]
