title: `or_else` yields every primary result, not just the first
grammar: typescript
asserts: types, values

The probe only decides which branch runs; the chosen branch then runs in full.

--- tql ---
main =
  children | is_kind :class_declaration
  | or_else (.body | children | is_kind :method_definition | .name | arr text)
            (pure "none");

--- source ---
class A { m() {} n() {} }

--- values ---
["m", "n"]

--- types ---
main : Node -> [String]
