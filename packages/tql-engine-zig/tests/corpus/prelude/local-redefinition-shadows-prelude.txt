title: the prelude is ordinary TQL and can be redefined locally
grammar: typescript
asserts: core, types, values

A local binding named `has` shadows the prelude's and behaves exactly as it
does, since `has` has no compiler special casing. This is evidence for the
claim that the prelude is ordinary higher-order TQL.

--- tql ---
import Data.Foldable (null);

methods = #body | children | of_kind :method_definition;

main =
  let { has p x = not (null (run p x)); }
  in children | of_kind :class_declaration | keep (has methods) | #name | arr text;

--- source ---
class Service { m() {} }
class Other {}

--- values ---
["Service"]

--- types ---
methods :: Filter Node Node
main :: Filter Node String

--- core ---
methods = compose_flipped (compose_flipped (Filter field[body]) children) (of_kind :method_definition)
main =
  let has = \p -> \x -> not (null (run p x)) in
  compose_flipped (compose_flipped (compose_flipped (compose_flipped children (of_kind :class_declaration)) (keep (has methods))) (Filter field[name])) (arr text)
