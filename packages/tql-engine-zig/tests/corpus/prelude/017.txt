title: the prelude is ordinary TQL and can be redefined locally
grammar: typescript
asserts: types, values

A local binding named `keep` behaves exactly as `select` does, since `select`
has no compiler special casing. This is evidence for the claim that the prelude
is ordinary higher-order TQL.

--- tql ---
main =
  let {
    keep p = branch p (arr identity) none
  } in
    children | is_kind :class_declaration
    | keep (.name | arr (\n -> text n ~ r"^S")) | .name | arr text;

--- source ---
class Service {}
class Other {}

--- values ---
["Service"]

--- types ---
main : Node -> [String]
