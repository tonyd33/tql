title: `any_m` and `all_m` share one scheme
grammar: typescript
asserts: types, values

Both helpers are applied to the same source and predicate, confirming they
accept identical argument types.

--- tql ---
main root =
  do {
    c <- (children | is_kind :class_declaration) root;
    some <- any_m (.body | children | is_kind :method_definition)
                (.name | arr (\n -> text n ~ r"^get")) c;
    every <- all_m (.body | children | is_kind :method_definition)
                 (.name | arr (\n -> text n ~ r"^get")) c;
    pure { some = some, every = every } c
  };

--- source ---
class A { getX() {} setY() {} }

--- values ---
[{ "every": false, "some": true }]

--- types ---
main : Node -> [{every: Bool, some: Bool}]
