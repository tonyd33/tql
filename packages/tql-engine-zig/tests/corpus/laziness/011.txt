title: a global cycle with no intervening binder diverges
grammar: typescript
asserts: types

Distinct from an unresolved-name error: `a` and `b` both resolve. The failure
is that forcing either re-enters an `evaluating` thunk with no lambda between
them, so no closure is built to defer the reference.

Contrast mutual recursion through function parameters, which terminates because
each body forces to a closure immediately.

Black-hole detection may report the re-entry; the specified semantics is
divergence, so a diagnostic is permitted, not required.

--- tql ---
a :: Node -> [String];
a = b;
b = a;
main = a;

--- types ---
a :: Node -> [String]
b :: Node -> [String]
main :: Node -> [String]
