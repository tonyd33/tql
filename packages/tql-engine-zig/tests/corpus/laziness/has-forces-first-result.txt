title: `has` forces at most the first result
grammar: typescript
asserts: types, values

`nats` is an infinite recursive filter. `has` terminates because it needs
only to know whether a first result exists. A strict implementation that
materialized the stream would not terminate.

--- tql ---
from n = always n <|> from (n + 1);
nats = from 0;
main = arr (has nats);

--- source ---
class A {}

--- values ---
[true]

--- types ---
from :: Alternative b => Int -> a -> b Int
nats :: Alternative b => a -> b Int
main :: Node -> [Bool]
