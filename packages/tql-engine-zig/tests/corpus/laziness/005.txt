title: a union is lazy in its right operand
grammar: typescript
asserts: types, values

The left operand alone satisfies `has`, so the infinite right operand is
never forced.

--- tql ---
from n = pure n <|> from (n + 1);
main = arr (has (pure 0 <|> from 1));

--- source ---
class A {}

--- values ---
[true]

--- types ---
from : Int -> a -> [Int]
main : Node -> [Bool]
