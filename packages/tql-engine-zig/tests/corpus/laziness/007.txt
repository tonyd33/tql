title: a recursive `let` group builds lazy thunks
grammar: typescript
pending: values

`step` refers to itself through a lambda, so forcing it terminates: the
self-reference is under a binder and is not entered until the function is
applied. This is well-defined only if the group's entries are lazy thunks over
the group's own environment.

The unguarded case `ones = 1, ones` is deliberately not used here: it diverges
rather than building a thunk, which is a different claim.

--- tql ---
main =
  let {
    step n = if n <= 0 then 0 else step (n - 1)
  } in
    pure (step 3);
