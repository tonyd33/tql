title: a global is forced at most once and memoized
grammar: typescript
asserts: types, values, stg

`shared` is referenced twice. Memoization is not directly observable as a
value, so the evidence here is only that both references agree; that a global
is forced at most once is not something a value assertion can witness.

--- tql ---
shared = 6 * 7;
main = const [shared, shared];

--- source ---
class A {}

--- values ---
[42, 42]

--- types ---
shared :: Int
main :: Node -> [Int]

--- stg ---
shared = {} \u {} -> op[*]# 6 7
main = {} \u {} ->
  let
    t2 = {} \u {} ->
      let
        t1 = {} \u {} ->
          let c0 = Nil in
          Cons shared c0@0
      in
      Cons shared t1@0
  in
  const t2@0
