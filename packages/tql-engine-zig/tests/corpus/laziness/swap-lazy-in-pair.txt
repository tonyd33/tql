title: `swap` takes its pair lazily
grammar: typescript
asserts: types, values

`swap` builds its pair without matching its argument, so a `case` that
only takes the pair apart does not force a diverging argument.

--- tql ---
import Data.Tuple (swap);

loop :: (Int, Int);
loop = loop;

main = pure $ case swap loop of {
  (_, _) -> 1;
};
