title: `any_m` short-circuits on the first match
grammar: typescript
asserts: types, values

The source is infinite but the predicate holds at 0, so the probe stops at the
first element. Termination is the evidence.

--- tql ---
from n = pure n, from (n + 1);
main = any_m (from 0) (arr (\x -> x >= 0));

--- source ---
class A {}

--- values ---
[true]

--- types ---
from : Int -> a -> [Int]
main : Node -> [Bool]
