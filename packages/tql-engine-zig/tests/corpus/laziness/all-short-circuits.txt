title: `all` short-circuits on the first violation
grammar: typescript
asserts: types, values

`and` does not force its second operand once the first is false, so `all`
stops at 0 despite the infinite source.

--- tql ---
import Data.Foldable (all);

from :: Int -> [Int];
from n = pure n <|> from (n + 1);
negative n = n < 0;
main = pure $ all negative (from 0);

--- source ---
class A {}

--- values ---
[false]

--- types ---
from :: Int -> [Int]
negative :: Int -> Bool
main :: Filter Node Bool
