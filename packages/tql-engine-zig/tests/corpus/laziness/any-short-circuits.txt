title: `any` short-circuits on the first match
grammar: typescript
asserts: types, values

`or` does not force its second operand once the first is true, so `any`
stops at 0 despite the infinite source.

--- tql ---
import Data.Foldable (any);

from n = always n <|> from (n + 1);
main root = return $ any (= 0) (from 0 root);

--- source ---
class A {}

--- values ---
[true]

--- types ---
from :: Alternative b => Int -> a -> b Int
main :: Node -> [Bool]
