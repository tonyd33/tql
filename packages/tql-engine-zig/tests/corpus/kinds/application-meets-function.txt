title: a type variable applied to an argument matches a function type
grammar: typescript
asserts: types, values

`f a` against `Int -> Int` makes `f` the function type short of its result,
`(->) Int`, and `a` the result. A filter is a function, so `Wrap children`
wraps one.

--- tql ---
data Wrap f a = Wrap (f a);

apply :: (f a -> b) -> f a -> b;
apply g x = g x;

wrapped = Wrap (+ 1);
wrapped_filter = Wrap children;

main root = [apply (\h -> h 1) (+ 1)];

--- source ---
class A {}

--- values ---
[2]
--- types ---
apply :: (a b -> c) -> a b -> c
wrapped :: Wrap ((->) Int) Int
wrapped_filter :: Wrap ((->) Node) [Node]
main :: Node -> [Int]
