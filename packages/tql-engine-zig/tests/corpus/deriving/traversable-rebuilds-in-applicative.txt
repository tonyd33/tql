title: a derived `traverse` rebuilds the value in the applicative, left to right
grammar: typescript
asserts: values

A failing element fails the whole traversal, and a field without the last
parameter is kept as it is.

--- tql ---
import Data.Foldable (to_list);
import Data.Traversable (traverse);

data Row a = Row String a (a, a) deriving (Functor, Foldable, Traversable);

positive x = if x > 0 then Just x else Nothing;

label r = case r of {
  Row s _ _ -> s;
};

main = Kleisli $ \_ -> [
  map to_list $ traverse positive $ Row "r" 1 (2, 3),
  map to_list $ traverse positive $ Row "r" 1 (0, 3),
  map (\r -> [length $ label r]) $ traverse positive $ Row "abc" 1 (2, 3),
];
