title: lists and booleans are ordered
grammar: typescript
asserts: values

`False` is declared before `True`, and `Nil` before `Cons`, so a list orders
before any longer list it is a prefix of.

--- tql ---
import Data.Function (const);

main = const [False < True, [1, 2] < [1, 3], [1] < [1, 0], [] < [0], [2] < [1, 5]];

--- source ---
class A {}

--- values ---
[true,true,true,true,false]
