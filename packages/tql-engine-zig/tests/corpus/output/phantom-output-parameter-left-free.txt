title: an output type parameter nothing constrains is left free
grammar: typescript
asserts: types, values

`P`'s derived `ToJson` instance needs nothing of `a`, so `ToJson (P a)` holds
whatever `a` is, and nothing has to determine it.

--- tql ---
data P a = P deriving (ToJson);

main = pure P;

class A {}

--- types ---
