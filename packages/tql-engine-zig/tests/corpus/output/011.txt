title: a node nested inside a record encodes as a node
grammar: typescript
asserts: types, values

`node` is `Serial`, so it may appear inside a serializable container.

--- tql ---
main = children | of_kind :class_declaration | arr (\c -> { at = range c, k = kind c });

--- source ---
class A {}

--- values ---
[
  {
    "at": {
      "end_byte": 10,
      "end_point": { "column": 10, "row": 0 },
      "start_byte": 0,
      "start_point": { "column": 0, "row": 0 }
    },
    "k": "class_declaration"
  }
]

--- types ---
main :: Node -> [{at: Range, k: Kind}]
