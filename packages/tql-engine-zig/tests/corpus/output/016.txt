title: `main = empty` is accepted when a signature fixes the type
grammar: typescript
pending: values

The signature fixes `b := string`, so `Serial string` is entailed and the
program is accepted. This is the boundary case that makes E-AMB-01 precise: the
rejection there is ambiguity, not `empty` itself.

--- tql ---
main : Filter node string;
main = empty;
