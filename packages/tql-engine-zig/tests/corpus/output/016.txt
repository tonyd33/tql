title: `main = none` is accepted when a signature fixes the type
grammar: typescript
asserts: types, values

The signature fixes `b := String`, so `Serial String` is entailed and the
program is accepted. This is the boundary case: an unannotated `main = none`
is rejected for ambiguity, not for `none` itself.

--- tql ---
main : Filter Node String;
main = none;

--- values ---
[]

--- types ---
main : Node -> [String]
