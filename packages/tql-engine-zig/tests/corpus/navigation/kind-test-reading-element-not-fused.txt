title: a kind test that reads the element it tests is not fused into the axis
grammar: typescript
asserts: simplified, values

The kind tested comes from `n` itself, so it is not known before `n` is
bound and the axis stays a plain walk.

--- tql ---
main = do {
  n <- descendants;
  if is_kind (kind n) n then return (text n) else empty;
};

--- source ---
class A {}

--- values ---
["class A {}", "class", "A", "{}", "{", "}"]

--- simplified ---
main = \x -> bind[List] (%descendants x) (
  \y -> case %is_kind (%kind y) y of
    False -> Nil
    True -> Cons (%text y) Nil
)
