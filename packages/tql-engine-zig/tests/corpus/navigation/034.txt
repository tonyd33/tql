title: `children` reaches a keyword under no field
grammar: typescript
asserts: types, values

`import type` and `import` have the same named children. Only the tokens tell
them apart.

--- tql ---
main = descendants_of_kind :import_statement
  | keep (has (children | keep (\t -> kind_name t = "type")))
  | arr text;

--- source ---
import type {a} from "./b";
import {a} from "./b";

--- values ---
["import type {a} from \"./b\";"]

--- types ---
main :: Node -> [String]
