title: `is_missing`, `is_error` and `has_error` tell recovered nodes from real ones
grammar: c
asserts: types, values

tree-sitter inserts the `;` that `int x = 1` lacks, as a missing node with
no text. `has_error` holds for every node above it.

--- tql ---
main = descendants
  | keep (\n -> kind_name n == ";" or has_error n)
  | arr (\n -> { kind = kind_name n, text = text n, missing = is_missing n, error = is_error n, has = has_error n });

--- source ---
int main() { int x = 1 return x; }
