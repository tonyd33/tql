title: `children` yields anonymous tokens outside fields
grammar: typescript
asserts: types, values

`type` in `import type` is an anonymous keyword outside any field.

--- tql ---

main = descendants_of_kind :import_statement | collect children | arr (map kind);

--- source ---
import type {a} from "./b";
import {a} from "./b";

--- values ---
[["import","type","import_clause","from","string",";"],["import","import_clause","from","string",";"]]

--- types ---
main :: Filter Node [Kind]
