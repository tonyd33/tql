title: descendant navigation is pre-order
grammar: typescript
asserts: core, simplified, types, values

Pre-order visits each node before its own descendants. `class_declaration` A
precedes its nested `method_definition` m, which precedes the later sibling
`class_declaration` B. A breadth-first or post-order walk would reorder these.
Anonymous tokens are visited in the same order. With no kind test the axis
is not fused.

--- tql ---
main = descendants | arr kind;

--- source ---
class A { m() {} }
class B {}

--- values ---
["class_declaration","class","type_identifier","class_body","{","method_definition","property_identifier","formal_parameters","(",")","statement_block","{","}","}","class_declaration","class","type_identifier","class_body","{","}"]

--- types ---
main :: Node -> [Kind]

--- core ---
main = kleisli descendants (arr kind)

--- simplified ---
main = kleisli %descendants (arr instance[Applicative,List] %kind)
