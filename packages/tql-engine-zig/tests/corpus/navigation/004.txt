title: child navigation does not descend
grammar: typescript
asserts: types, values

Only the top-level class is a child of `program`. The nested method is a
descendant but not a child, so `children` does not reach it.

--- tql ---
main = children | of_kind :method_definition | #name | arr text;

--- source ---
class A { m() {} }

--- values ---
[]

--- types ---
main :: Node -> [String]
