title: a join point bound inside a case scrutinee jumps within it
grammar: typescript
asserts: core, simplified, stg, values

The scrutinee runs in a nested evaluation, and the jump stays inside it.

--- tql ---
import Data.Function (const);

total xs = case xs of { [] -> 0; h : t -> h + total t };
label xs = case (case xs of { [x] -> x > 10; ys -> total ys + total ys * 2 + total ys * 3 > 10 }) of {
  True -> "big";
  False -> "small";
};
main = const [label [1], label [1, 2], label [20]];
