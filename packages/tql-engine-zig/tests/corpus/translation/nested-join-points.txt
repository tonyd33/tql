title: a shared alternative whose body shares an alternative nests join points
grammar: typescript
asserts: core, simplified, stg, values

The inner join point is bound in the outer one's body, at a greater depth.

--- tql ---
import Data.Function (const);

total xs = case xs of { [] -> 0; h : t -> h + total t };
k xs ys = case xs of {
  [x] -> x;
  _ -> case ys of { [y] -> y; zs -> total zs + total zs * 2 + total zs * 3 };
};
main = const [k [1] [], k [] [2], k [1, 1] [3, 4], k [] []];
