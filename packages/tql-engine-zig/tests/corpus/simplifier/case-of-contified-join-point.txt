title: a case of a local function called in tail position moves into its body
grammar: typescript
asserts: simplified, stg, values

Once `g` is a join point, the `case` around its scope moves into its body
and its jumps drop it.

--- tql ---
import Data.Function (const);

f b x = case (let { g y = y * 2 + y * 3 + y * 4 + y * 5 > 20 } in if b then g x else g (x + 1)) of { True -> "big"; False -> "small" };
main = const [f True 1, f False 1];

--- source ---
class A {}

--- values ---
["small","big"]

--- simplified ---
f = \b -> \x ->
  join
    g y = case %gt_int (op[+] (op[+] (op[+] (op[*] y 2) (op[*] y 3)) (op[*] y 4)) (op[*] y 5)) 20 of
      False -> "small"
      True -> "big"
  in
  case b of
    False -> jump g (op[+] x 1)
    True -> jump g x
main = const (Cons (f True 1) (Cons (f False 1) Nil))
