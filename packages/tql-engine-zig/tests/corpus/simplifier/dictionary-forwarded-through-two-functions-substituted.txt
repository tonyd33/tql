title: a dictionary forwarded from one function to another is substituted into both
grammar: typescript
asserts: simplified, values

`twice` passes its dictionary on to `size`, and every call of `twice` passes
`Sized List`. Both are too large to inline, and both take no dictionary.

--- tql ---
size :: Sized s => s -> Int;
size xs = length xs + length xs * 2 + length xs * 3;

twice :: Sized s => s -> Int;
twice xs = size xs + size xs * 2 + size xs * 3;

main = Filter (\_ -> [twice [1], twice [1, 2]]);
