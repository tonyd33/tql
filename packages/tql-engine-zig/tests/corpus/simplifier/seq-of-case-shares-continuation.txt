title: a case with only a default moves into a case scrutinee as a join point of no parameters
grammar: typescript
asserts: simplified, values

`seq` is a case with only a default. Each inner alternative is evaluated,
so each takes the default, which is too large to copy.

--- tql ---
f b x = seq (if b then [1] else [2]) (x * 2 + x * 3);
main = Filter (\_ -> [f True 1, f False 2]);

--- source ---
class A {}

--- values ---
[5,10]
--- simplified ---
f = \b -> \x ->
  join j = op[+] (op[*] x 2) (op[*] x 3) in
  case b of
    False -> jump j
    True -> jump j
main = \_ -> Cons (f True 1) (Cons (f False 2) Nil)
