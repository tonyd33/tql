title: a lambda argument the function applies brings it under the threshold
grammar: typescript
asserts: core, simplified, values

`combine` is just over the inlining threshold. Called with a lambda, each
application of `k` is removed and the call is inlined; called with the
parameter `g` it stays a call.

--- tql ---
import Data.Function (const);

combine :: (Int -> Int -> Int) -> Int;
combine k = k 1 2 + k 3 4;

via :: (Int -> Int -> Int) -> Int;
via g = combine g;

main = const [combine (\a b -> a), via (\a b -> b)];

--- source ---
class A {}

--- values ---
[4, 6]

--- simplified ---
combine = \k -> op[+] (k 1 2) (k 3 4)
via = \g -> combine g
main = const (Cons (op[+] 1 3) (Cons (op[+] 2 4) Nil))

--- core ---
combine = \k -> op[+] (k 1 2) (k 3 4)
via = \g -> combine g
main = const (Cons (combine (\a -> \b -> a)) (Cons (via (\a -> \b -> b)) Nil))
