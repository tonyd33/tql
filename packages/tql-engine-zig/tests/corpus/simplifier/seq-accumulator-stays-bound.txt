title: an accumulator forced by seq and passed on stays bound
grammar: typescript
asserts: simplified, values

`z2` is used twice. Inlining it would leave the second use an unforced copy,
and the chain of thunks a strict fold exists to avoid would return.

--- tql ---
fold :: (b -> a -> b) -> b -> [a] -> b;
fold f z xs = case xs of {
  [] -> z;
  h : t -> let { z2 = f z h; } in seq z2 (fold f z2 t);
};
main = always (fold (\n x -> n + x) 0 [1, 2, 3]);
