title: case of case binds large outer alternatives as join points
grammar: typescript
asserts: simplified, stg, values

The outer alternatives are copied into both inner ones, so each one too
large to copy becomes a join point first.

--- tql ---
import Data.Function (const);

total xs = case xs of { [] -> 0; h : t -> h + total t };
f b xs = case (if b then xs else []) of {
  [] -> total xs * 2 + total xs * 3;
  h : t -> h + total t * 2 + total t * 3;
};
main = const [f True [1, 2], f False [1, 2], f True []];
