title: a case binder of a known constructor shares its fields with the alternative's binders
grammar: typescript
asserts: simplified, values

`h` and `ys` both read `total xs`, which is computed once.

--- tql ---
total :: [Int] -> Int;
total xs = case xs of {
  [] -> 0;
  h : t -> h + total t;
};
f :: [Int] -> Int;
f xs = let { ys = [total xs]; } in case ys of {
  [] -> 0;
  h : _ -> h + length ys;
};
main = pure (f [1, 2, 3]);
