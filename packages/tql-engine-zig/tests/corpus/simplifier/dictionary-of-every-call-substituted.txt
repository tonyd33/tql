title: a dictionary every call passes is substituted into a global
grammar: typescript
asserts: simplified, values

`size` is too large to inline. Both calls pass `Sized List`, so `size`
selects `length[List]` and takes no dictionary.

--- tql ---
import Data.Function (const);

size :: Sized s => s -> Int;
size xs = length xs + length xs * 2 + length xs * 3;

main = const [size [1], size [1, 2]];

--- source ---
class A {}
