title: a failed bind at `Maybe` skips the statements after it
grammar: typescript
asserts: simplified, values

At `List` a failed match drops one element and the block goes on with the
next. At `Maybe` there is one value, so the whole block is `Nothing`.

--- tql ---
import Data.Maybe (Maybe(..));

checked m = do {
  x <- m;
  1 <- Just x;
  return (x + 10);
};

over_list xs = do {
  x <- xs;
  1 <- [x];
  return (x + 10);
};

main root = [{at_maybe = [checked (Just 1), checked (Just 2)], at_list = over_list [1, 2, 1]}];

checked = \m -> case m of

  \x -> bind[List] (Cons x Nil) (
