title: a list pattern bound at `Maybe` matches the list inside the `Just`
grammar: typescript
asserts: types, simplified, values

The bound value is a `Maybe [Int]`, so the pattern matches the list the
`Just` holds, once. A list of another length is `Nothing`, not a filtered
list.

--- tql ---
import Data.Maybe (Maybe(..));

sum_of_two m = do {
  [a, b] <- m;
  return (a + b);
};

main root = [sum_of_two (Just [1, 2]), sum_of_two (Just [1]), sum_of_two Nothing];
