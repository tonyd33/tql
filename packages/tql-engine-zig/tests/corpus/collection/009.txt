title: list equality is element-wise and order-sensitive
grammar: typescript
asserts: types
pending: values

Lists are ordered, so a different order is a different value. Lists of
different length are never equal.

--- tql ---
main root =
  let {
    ab = [pure "a", pure "b"] root;
    a = [pure "a"] root
  } in
    (pure (ab = ab), pure (a = ab)) root;
