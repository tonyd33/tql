title: nested collection
grammar: typescript
asserts: types, values

The outer `collect` gathers the per-class lists into one list of lists.

--- tql ---
main =
  collect (children | is_kind :class_declaration
   | collect (.body | children | is_kind :method_definition | .name | arr text));

--- source ---
class A { m() {} n() {} }
class B { p() {} }

--- values ---
[[["m", "n"], ["p"]]]

--- types ---
main : Node -> [[[String]]]
