title: `[]` is an empty list, not an empty query
grammar: typescript
asserts: types, values

`[]` yields one value, and that value is the empty list. `none` yields no
output at all. The distinction is the rule.

--- tql ---
main root = do { xs <- [] root; pure (length xs) root };

--- source ---
class A {}

--- values ---
[0]

--- types ---
main : Node -> [Int]
