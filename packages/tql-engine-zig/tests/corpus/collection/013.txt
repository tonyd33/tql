title: field order is irrelevant for equality and type identity
grammar: typescript
asserts: core, types, values

The two record expressions list their labels in opposite order. They are the
same value and the same type.

--- tql ---
main =
  let {
    x = { a = 1, b = 2 };
    y = { b = 2, a = 1 };
  }
  in pure (x = y);

--- source ---
class A {}

--- values ---
[true]

--- types ---
main :: Node -> [Bool]

--- core ---
main =
  letrec
    x = record[a,b] 1 2
    y = record[a,b] 1 2
  in
  pure (op[=] x y)
