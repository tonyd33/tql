title: `[p]` collects every output of `p` into exactly one list
grammar: typescript
asserts: core, types, values

The result is one value, not three: collection changes multiplicity.

--- tql ---
main = [children | is_kind :class_declaration | .name | arr text];

--- source ---
class A {}
class B {}
class C {}

--- values ---
[["A", "B", "C"]]

--- core ---
main = arr (kleisli (kleisli (kleisli children is_kind[class_declaration]) field[name]) (arr text))

--- types ---
main : Node -> [[String]]
