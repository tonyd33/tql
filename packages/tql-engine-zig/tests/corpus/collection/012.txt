title: a multi-valued field is collected into a list field
grammar: typescript
asserts: types, values

A field holds one value, so a query yielding many is collected at the field.
An empty query gives an empty list and the record is still built. The record no
longer annihilates, because there is no product to annihilate.

--- tql ---
main root =
  do {
    b <- [children | is_kind :interface_declaration | lift text] root;
    pure { a = 1, b = b } root
  };

--- source ---
class A {}

--- values ---
[{ "a": 1, "b": [] }]

--- types ---
main : Node -> [{a: Int, b: [String]}]
