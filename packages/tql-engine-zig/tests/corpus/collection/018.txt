title: a list literal is a scalar list
grammar: typescript
asserts: core, types, values

`[a, b, c]` is `Cons a (Cons b (Cons c Nil))`. It is one value, so it needs
`pure` to become an output.

--- tql ---
main = pure [1, 1 + 1, 3];

--- values ---
[[1, 2, 3]]

--- types ---
main :: Node -> [[Int]]

--- core ---
main = pure (Cons 1 (Cons (op[+] 1 1) (Cons 3 Nil)))
