title: a `do` bind over a non-node stream
grammar: typescript
asserts: core, types, values

A bind is not node-specific; it binds each element of any list.

--- tql ---
main _ = do {
  n <- [1, 2, 3];
  return $ n * 10;
};

--- source ---
class A {}

--- values ---
[10, 20, 30]

--- types ---
main :: Node -> [Int]

--- core ---
main = \_ -> concat_map (\n -> return (op[*] n 10)) (Cons 1 (Cons 2 (Cons 3 Nil)))
