title: a `do` bind over a non-node stream
grammar: typescript
asserts: types, values

Stream binding is not node-specific; it binds any filter's outputs.

--- tql ---
main _root =
  do {
    n <- const [1, 2, 3] _root;
    pure (n * 10) _root
  };

--- source ---
class A {}

--- values ---
[10, 20, 30]

--- types ---
main : Node -> [Int]
