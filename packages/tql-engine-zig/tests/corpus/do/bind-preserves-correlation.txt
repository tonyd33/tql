title: an outer bind stays correlated with each inner bind
grammar: typescript
asserts: types, values

Each method is paired with the class it came from: the outer binding stays in
scope inside the inner branch.

--- tql ---
main = do {
  c <- children_of_kind :class_declaration;
  m <- pure c | #body | children | of_kind :method_definition;
  cn <- pure c | #name;
  mn <- pure m | #name;
  return { class = text cn, method = text mn };
};

--- source ---
class A { m() {} n() {} }
class B { p() {} }

--- values ---
[
  { "class": "A", "method": "m" },
  { "class": "A", "method": "n" },
  { "class": "B", "method": "p" }
]

--- types ---
main :: Filter Node {class: String, method: String}
