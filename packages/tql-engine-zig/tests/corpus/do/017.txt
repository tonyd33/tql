title: `do` nested inside a pipe stage
grammar: typescript
asserts: types, values

The block runs once per input value from the left stage.

--- tql ---
main =
  children | is_kind :class_declaration
  | \c -> do { m <- (.body | children | is_kind :method_definition) c;
               (.name | lift text) m };

--- source ---
class A { m() {} }
class B { p() {} }

--- values ---
["m", "p"]

--- types ---
main : Node -> [String]
