title: the last item in the braces is the final expression
grammar: typescript
asserts: types
pending: values

Each `name <- query` is terminated by `;`. The last item carries no `;`
separating it from a successor, so it is the unique final expression. Compare a
block with no statements at all, whose final expression is its only item.

--- tql ---
main root =
  do {
    c <- (children | is_kind :class_declaration) root;
    m <- (.body | children | is_kind :method_definition) c;
    (.name | lift text) m
  };

--- source ---
class A { m() {} }

--- values ---
["m"]

--- types ---
