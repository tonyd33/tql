title: the last item in the braces is the final expression
grammar: typescript
pending: values

Each `name <- query` is terminated by `;`. The last item carries no `;`
separating it from a successor, so it is the unique final expression. Compare
DO-12, where the block has no statements at all.

--- tql ---
main root =
  do {
    c <- (children | is_kind :class_declaration) root;
    m <- (children | is_kind :method_definition) c.body;
    (.name | text) m
  };

--- source ---
class A { m() {} }
