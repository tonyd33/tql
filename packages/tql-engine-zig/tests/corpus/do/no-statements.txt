title: a `do` block with no statements is permitted
grammar: typescript
asserts: core, types, values

It evaluates to its final expression.

--- tql ---
main = do {
  children_of_kind :class_declaration | arr text;
};

--- source ---
class A {}

--- values ---
["class A {}"]

--- types ---
main :: Filter Node String

--- core ---
main = compose_flipped (children_of_kind :class_declaration) (arr text)
