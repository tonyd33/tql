title: stream binding preserves correlation between outputs
grammar: typescript
asserts: types, values

This is the case that motivated replacing `as`. Each method is paired with the
class it came from, because the outer binding stays in scope inside the inner
branch. A formulation that lost the outer node could not produce these pairs.

--- tql ---
main root = do {
  c <- children_of_kind :class_declaration root;
  m <- (.body | children | of_kind :method_definition) c;
  cn <- c.name;
  mn <- m.name;
  return { class = text cn, method = text mn };
};

--- source ---
class A { m() {} n() {} }
class B { p() {} }

--- values ---
[
  { "class": "A", "method": "m" },
  { "class": "A", "method": "n" },
  { "class": "B", "method": "p" }
]

--- types ---
main :: Node -> [{class: String, method: String}]
