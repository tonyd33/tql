title: the binding is branch-local and immutable
grammar: typescript
asserts: types
pending: values

Each branch of the outer bind has its own `c`. The inner record sees the `c` of
its own branch, never a later one.

--- tql ---
main root =
  do {
    c <- (children | is_kind :class_declaration) root;
    n <- (pure 1, pure 2) root;
    cn <- c.name;
    { class = pure (text cn), n = pure n } root
  };

--- source ---
class A {}
class B {}
