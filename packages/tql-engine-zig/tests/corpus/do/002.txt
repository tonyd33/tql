title: the body receives the bound value as its current input
grammar: typescript
asserts: types, values

The final expression reports the kind of `c`, the class node, rather than the
root.

--- tql ---
main root = do {
  c <- children_of_kind :class_declaration root;
  return $ kind c;
};

--- source ---
class A {}

--- values ---
["class_declaration"]

--- types ---
main : Node -> [String]
