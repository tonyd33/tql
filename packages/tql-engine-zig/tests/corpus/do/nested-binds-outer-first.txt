title: nested binds enumerate the outer bind outermost
grammar: typescript
asserts: core, types, values

The rule under test is ordering. The first bind is the outer generator: 10
pairs with 1 then 2, then 20 pairs with 1 then 2, giving 11, 12, 21, 22.
Varying the first bind fastest would give 11, 21, 12, 22.

--- tql ---
sums = do {
  l <- [10, 20];
  r <- [1, 2];
  return $ l + r;
};

main = Filter (\_ -> sums);

--- source ---
class A {}

--- values ---
[11, 12, 21, 22]

--- types ---
sums :: [Int]
main :: Filter Node Int

--- core ---
sums = bind (Cons 10 (Cons 20 Nil)) (\l -> bind (Cons 1 (Cons 2 Nil)) (\r -> return (op[+] l r)))
main = Filter (\_ -> sums)
