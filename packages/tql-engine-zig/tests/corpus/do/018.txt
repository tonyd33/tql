title: `do` and explicit pipe agree when no correlation is needed
grammar: typescript
asserts: types, values

Stream bind degenerates to pipe when the body does not need the binding. Both
spellings appear in one union, so their streams are directly comparable: the
first two values come from the `do` form and the last two from the pipe form.

--- tql ---
main =
  (\root -> do {
     c <- (children | is_kind :class_declaration) root;
     (.name | arr text) c
   })
  <|> (children | is_kind :class_declaration | .name | arr text);

--- source ---
class A {}
class B {}

--- values ---
["A", "B", "A", "B"]

--- types ---
main : Node -> [String]
