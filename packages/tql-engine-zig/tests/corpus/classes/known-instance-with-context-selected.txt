title: a method of a known instance with a context is selected
grammar: typescript
asserts: simplified, values

`describe` at `[Shape]` selects from `Describe [a]` applied to the known
`Describe Shape` dictionary, so the call goes to the list instance's
implementation and no list dictionary is built. Every call of that
implementation passes `Describe Shape`, so it takes no dictionary.

--- tql ---
class Describe a where {
  describe :: a -> [String];
};

data Shape = Circle Int | Square Int;

instance Describe Shape where {
  describe s = case s of { Circle _ -> ["circle"]; Square _ -> ["square"] };
};

instance Describe a => Describe [a] where {
  describe xs = case xs of {
    [] -> [];
    x : rest -> append (describe x) (describe rest);
  };
};

main root = describe [Circle 1];

--- source ---
class A {}

--- values ---
["circle"]

--- simplified ---
main = \root -> describe[List] (Cons (Circle 1) Nil)
