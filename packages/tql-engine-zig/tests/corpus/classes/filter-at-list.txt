title: `filter` keeps the elements of a list a predicate holds for
grammar: typescript
asserts: types, values

`filter` is `Data.List`'s, at lists only. `mfilter` is the one over any
monad with an `Alternative`.

--- tql ---
import Data.List (filter);

main root = filter (\x -> x > 0) [0, 1, -2, 3];

class A {}
