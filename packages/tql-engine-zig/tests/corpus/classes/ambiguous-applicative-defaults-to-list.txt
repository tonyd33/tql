title: an applicative nothing determines defaults to `List`
grammar: typescript
asserts: types, values

`pure (x + 1)` is some `f Int` with `Applicative f`, and `length` needs
`Sized (f Int)`. Nothing else fixes `f`, and `List` satisfies both, so
`count` takes no dictionary.

--- tql ---
count x = length (pure (x + 1));

main = pure (count 1);
