title: `Ord` gives `=` through its superclass
grammar: typescript
asserts: types, values

`within` asks only for `Ord a`, and its `=` needs `Eq a`, which `Ord a`
implies.

--- tql ---
within :: Ord a => a -> a -> a -> Bool;
within lo hi x = lo <= x and x = x and x <= hi;
main = const [within 1 3 2, within "a" "b" "c"];

--- source ---
class A {}

--- values ---
[true,false]

--- types ---
within :: Ord a => a -> a -> a -> Bool
main :: Node -> [Bool]
