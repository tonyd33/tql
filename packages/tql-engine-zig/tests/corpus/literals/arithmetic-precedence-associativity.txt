title: arithmetic precedence and left associativity
grammar: typescript
asserts: core, types, values

`2 + 3 * 4` is `2 + (3 * 4)`; `10 - 3 - 2` is `(10 - 3) - 2`.

--- tql ---

main = Kleisli $ \_ -> [2 + 3 * 4, 10 - 3 - 2];

--- source ---
class A {}

--- values ---
[14, 5]

--- types ---
main :: Kleisli List Node Int

--- core ---
main = Kleisli (\_ -> Cons (op[+] 2 (op[*] 3 4)) (Cons (op[-] (op[-] 10 3) 2) Nil))
