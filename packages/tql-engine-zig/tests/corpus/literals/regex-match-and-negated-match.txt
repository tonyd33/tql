title: `~` matches node text against a regex and `!~` negates it
grammar: typescript
asserts: core, types, values

--- tql ---
main = children | of_kind :class_declaration
  | #name
  | arr (\n -> [text n ~ r"^Ser", text n !~ r"^Ser"])
;
