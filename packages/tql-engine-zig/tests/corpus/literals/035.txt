title: field access binds tighter than application
grammar: typescript
asserts: core, types, values

`map text n.name` groups as `map text (n.name)`, not `(map text n).name`.

Field access yields a list, so `n.name` is a `[Node]` rather than a `Node`, and
`map text` maps over it.

--- tql ---
name_of n = map text n#name;
main = children | of_kind :class_declaration | name_of;

--- source ---
class A {}

--- values ---
["A"]

--- types ---
name_of :: Node -> [String]
main :: Node -> [String]

--- core ---
name_of = \n -> map text (field[name] n)
main = kleisli (kleisli children (of_kind :class_declaration)) name_of
