title: application binds tighter than query infix operators
grammar: typescript
asserts: core, types, values

`add 1 2 + add 3 4` groups as `(add 1 2) + (add 3 4)`, not `add 1 (2 + add) 3 4`.

--- tql ---
add x y = x + y;
main = pure $ add 1 2 + add 3 4;

--- source ---
class A {}

--- values ---
[10]

--- types ---
add :: Int -> Int -> Int
main :: Node -> [Int]

--- core ---
add = \x -> \y -> op[+] x y
main = pure (op[+] (add 1 2) (add 3 4))
