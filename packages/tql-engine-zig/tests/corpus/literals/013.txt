title: a zero divisor anywhere in a stream is undefined
grammar: typescript
asserts: types

Scalar operators have no way to drop a pair, so the whole query is undefined
once a zero divisor reaches `mod`. It typechecks; it has no value.

--- tql ---
main _ = do {
  d <- [5, 0, 7];
  return $ 12 `mod` d;
};

--- source ---
class A {}

--- types ---
main :: Node -> [Int]
