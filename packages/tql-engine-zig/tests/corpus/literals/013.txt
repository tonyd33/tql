title: a zero divisor anywhere in a stream is undefined
grammar: typescript
asserts: types

This case pinned the old pruning rule: three moduli, the zero pair dropped,
the survivors keeping their left-major order. Scalar operators have no way to
drop a pair, so the whole query is undefined once a zero divisor reaches one.
It typechecks; it has no value.

--- tql ---
main = \root -> do { d <- (pure 5, pure 0, pure 7) root; pure (12 % d) root };

class A {}

--- types ---
