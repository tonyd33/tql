title: the closing quote ends the literal
grammar: typescript
asserts: core, types, values

`r"^A"` is a complete regex literal; the following `,` ends the element, not
more pattern. Delimiting with `"` rather than `/` is what leaves `/` with exactly
one meaning in every position.

--- tql ---
main = const ["A" ~ r"^A", "B" ~ r"^A"];

--- source ---
class A {}

--- values ---
[true, false]

--- types ---
main :: Node -> [Bool]

--- core ---
main = const (Cons (op[~] "A" r"^A") (Cons (op[~] "B" r"^A") Nil))
