title: `True` and `False` print as JSON booleans
grammar: typescript
asserts: core, types, values

A list has one element type, so this case lists bools only.

--- tql ---

main = Filter (\_ -> [True, False, True]);

--- source ---
class A {}

--- values ---
[true, false, true]

--- core ---
main = Filter (\_ -> Cons True (Cons False (Cons True Nil)))

--- types ---
main :: Filter Node Bool
