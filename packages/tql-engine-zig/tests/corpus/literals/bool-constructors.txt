title: `true` and `false` are the `Bool` constructors
grammar: typescript
asserts: core, types, values

A list has one element type, so this case lists bools only.

--- tql ---
import Data.Function (const);

main = const [true, false, true];

--- source ---
class A {}

--- values ---
[true, false, true]

--- core ---
main = const (Cons True (Cons False (Cons True Nil)))

--- types ---
main :: Node -> [Bool]
