title: node equality is identity-based
grammar: typescript
asserts: types, values

Both operands select the same single node, so the pair is that node against
itself.

--- tql ---
main root =
  do { l <- (children | is_kind :class_declaration) root;
       r <- (children | is_kind :class_declaration) root;
       pure (l = r) root };

--- source ---
class A {}

--- values ---
[true]

--- types ---
main : Node -> [Bool]
