title: node equality is identity-based
grammar: typescript
asserts: types, values

Both operands select the same single node, so the pair is that node against
itself.

--- tql ---
main root = do {
  l <- children_of_kind :class_declaration root;
  r <- children_of_kind :class_declaration root;
  return $ l = r;
};

--- source ---
class A {}

--- values ---
[true]

--- types ---
main :: Node -> [Bool]
