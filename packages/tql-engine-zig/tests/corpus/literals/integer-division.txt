title: div and mod floor, quot and rem truncate, and every pair is defined
grammar: typescript
asserts: values

Each pair satisfies `q * b + r == a` for every `a` and `b`. A zero divisor
gives quotient 0 and remainder `a`, and the least `Int` divided by `-1`
wraps to itself with remainder 0.

--- tql ---
import Data.Int (div, mod, quot, rem);

least = 0 - 9223372036854775807 - 1;

main = pure (
  [
    [div 7 2, mod 7 2, quot 7 2, rem 7 2],
    [div (-7) 2, mod (-7) 2, quot (-7) 2, rem (-7) 2],
    [div 7 (-2), mod 7 (-2), quot 7 (-2), rem 7 (-2)],
    [div (-7) (-2), mod (-7) (-2), quot (-7) (-2), rem (-7) (-2)],
    [div 7 0, mod 7 0, quot (-7) 0, rem (-7) 0]
  ],
  [div least (-1) == least, mod least (-1) == 0, quot least (-1) == least, rem least (-1) == 0]
);
