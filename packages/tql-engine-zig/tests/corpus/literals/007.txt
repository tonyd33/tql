title: a raw literal needs no escape for a slash
grammar: typescript
asserts: types, values

`r"a/b"` is the three-character pattern `a/b`. A `/` is not special inside the
literal, so it needs no escape; only `"` closes it.

--- tql ---
main = descendants | of_kind :string | arr (\s -> text s ~ r"a/b");

--- source ---
let p = "xa/by";

--- values ---
[true]

--- types ---
main : Node -> [Bool]
