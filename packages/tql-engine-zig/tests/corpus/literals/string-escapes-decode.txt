title: string literal escapes decode
grammar: typescript
asserts: types, values, core

`\"`, `\\`, `\n`, `\t` and `\r` each decode to one character, so
`"\"ab\""` has length 4. Core prints the literal re-escaped.

--- tql ---

main = Filter (\_ -> [length "\"ab\"", length "a\\b", length "\n\t\r"]);

--- source ---
class A {}

--- values ---
[4, 3, 3]

--- types ---
main :: Filter Node Int

--- core ---
main = Filter (\_ -> Cons (length "\"ab\"") (Cons (length "a\\b") (Cons (length "\n\t\r") Nil)))
