title: pipe binds looser than comparison, union looser than pipe
grammar: typescript
asserts: types, values

The whole pipeline is the left operand of `<|>`. Union is the loosest
operator, so it splits the expression last. Were it tighter than pipe, the last
stage would be `arr (...) <|> pure false` and every class would yield an extra
`false`.

Both union operands yield `Bool`, since union requires a single element type.

--- tql ---
main = children | of_kind :class_declaration
  | .name
  | arr (\n -> text n = "A")
  <|> pure false
;

--- source ---
class A {}
class B {}

--- values ---
[true, false, false]

--- types ---
main : Node -> [Bool]
