title: pipe binds looser than comparison, union looser than pipe
grammar: typescript
pending: values

`. / :class_declaration | .name | text = "A", false` groups as
`((. / :class_declaration | .name | text) = "A"), false`. Union is the loosest
operator, so it splits the expression last; pipe splits before comparison.

Both union operands are `bool`, since union requires a single element type.

--- tql ---
main = . / :class_declaration | .name | text = "A", false;

--- source ---
class A {}

--- values ---
[true, false]
