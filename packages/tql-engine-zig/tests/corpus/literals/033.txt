title: pipe binds looser than comparison and union
grammar: typescript
asserts: core, types, values

The last stage is `arr (...) <|> pure false`, so every class yields an extra
`false`. Parenthesize the pipeline to make it the left operand of `<|>`.

Both union operands yield `Bool`, since union requires a single element type.

--- tql ---
main = children | of_kind :class_declaration
  | #name
  | arr (\n -> text n = "A")
  <|> pure false
;

--- source ---
class A {}
class B {}

--- values ---
[true, false, false, false]

--- types ---
main :: Node -> [Bool]

--- core ---
main = kleisli (kleisli (kleisli children (of_kind :class_declaration)) field[name]) (alt (arr (\n -> op[=] (text n) "A")) (pure False))
