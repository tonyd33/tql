title: a literal ignores its input and yields once per input value
grammar: typescript
asserts: types, values

Two class declarations give two inputs to the right stage, so `pure` runs
twice.

--- tql ---
main = children | of_kind :class_declaration | pure 1;

--- source ---
class A {}
class B {}

--- values ---
[1, 1]

--- types ---
main :: Node -> [Int]
