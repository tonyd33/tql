title: application binds tighter than query infix operators
grammar: typescript
asserts: types, values

`add 1 2 + add 3 4` groups as `(add 1 2) + (add 3 4)`, not `add 1 (2 + add) 3 4`.

--- tql ---
add x y = x + y;
main = pure $ add 1 2 + add 3 4;

--- source ---
class A {}

--- values ---
[10]

--- types ---
add : Int -> Int -> Int
main : Node -> [Int]
