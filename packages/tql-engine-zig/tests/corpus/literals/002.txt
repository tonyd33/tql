title: bool literals in filter position
grammar: typescript
asserts: core, types, values

A list has one element type, so this fixture lists bools only. LIT-01
covers `int` and REGEX-05 covers a `string`-producing program.

--- tql ---
main = const [true, false, true];

--- source ---
class A {}

--- values ---
[true, false, true]

--- core ---
main = const (Cons True (Cons False (Cons True Nil)))

--- types ---
main :: Node -> [Bool]
