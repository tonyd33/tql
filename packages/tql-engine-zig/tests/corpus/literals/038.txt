title: a string literal containing quotes compares against node text
grammar: typescript
asserts: values

A JSON-style key's text includes its quotes, which a literal writes as `\"`.

--- tql ---
main = descendants_of_kind :string | keep (\s -> text s = "\"compilerOptions\"") | arr text;

--- source ---
const x = { "compilerOptions": 1, "other": 2 };

--- values ---
["\"compilerOptions\""]
