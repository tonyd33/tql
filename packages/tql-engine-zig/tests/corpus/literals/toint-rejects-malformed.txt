title: `toint` rejects non-integer strings with the empty stream
grammar: typescript
asserts: types, values

Each rejected form is a separate reason: a plain word, a float, a leading plus,
an internal space, and the empty string. None is an error.

--- tql ---
main = const ["abc", "1.5", "+3", "1 2", ""] | toint;

--- source ---
class A {}

--- values ---
[]

--- types ---
main :: Node -> [Int]
