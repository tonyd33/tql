title: `toint` gives `Nothing` for a non-integer string
grammar: typescript
asserts: types, values

Each rejected form is a separate reason: a plain word, a float, a leading plus,
an internal space, and the empty string. None is an error.

--- tql ---
import Data.Int (toint);

main = pure $ map toint ["abc", "1.5", "+3", "1 2", ""];
