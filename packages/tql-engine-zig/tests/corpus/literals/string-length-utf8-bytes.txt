title: `length` of a string is its UTF-8 byte length
grammar: typescript
asserts: types, values

`"héllo"` is five characters but six UTF-8 bytes: `é` occupies two. Byte
length, not character count, is the rule.

--- tql ---

main = Filter (\_ -> ["hello", "héllo"]) | arr length;

--- source ---
class A {}

--- values ---
[5, 6]

--- types ---
main :: Filter Node Int
