title: `pure` ignores its input and yields once per input
grammar: typescript
asserts: types, values

Two class declarations give `pure 1` two inputs, so `pure` runs
twice.

--- tql ---
main = children | of_kind :class_declaration | pure 1;

--- source ---
class A {}
class B {}

--- values ---
[1, 1]

--- types ---
main :: Node -> [Int]
