title: a binding evaluates as a value and does not run a filter
grammar: typescript
pending: values

Binding `k` does not execute it. Two uses of `k` on different inputs give
different results, which is only possible if the binding stored the filter
rather than its output.

--- tql ---
main =
  let {
    k = kind
  } in
    . / :class_declaration | k, . // :property_identifier | k;

--- source ---
class A { m() {} }
