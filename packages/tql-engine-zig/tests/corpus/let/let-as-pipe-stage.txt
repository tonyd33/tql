title: `let` inside a pipe stage
grammar: typescript
asserts: core, types, values

The group is evaluated once, outside the stage function. The bound filter runs
on each input from the left stage.

--- tql ---
main =
  children | of_kind :class_declaration
  | let { n = #name | arr text } in n;

--- source ---
class A {}
class B {}

--- values ---
["A", "B"]

--- types ---
main :: Kleisli List Node String
entry :: Node -> [String]

--- core ---
main = compose_flipped (compose_flipped children (of_kind :class_declaration)) (
  let n = compose_flipped (Kleisli field[name]) (arr text) in
  n
)
entry = run_main main
