title: a `let` group is a recursive SCC
grammar: typescript
asserts: core, types, values

`countdown` refers to itself. The group is inferred as a recursive SCC, so a
self-reference resolves without a forward declaration.

--- tql ---
main =
  let { countdown n = if n <= 0 then 0 else countdown (n - 1); }
  in pure (countdown 3);

--- source ---
class A {}

--- values ---
[0]

--- types ---
main :: Node -> [Int]

--- core ---
main =
  letrec
    countdown = \n -> case op[<=] n 0 of
      False -> countdown (op[-] n 1)
      True -> 0
  in
  pure (countdown 3)
