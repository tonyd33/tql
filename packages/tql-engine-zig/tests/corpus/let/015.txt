title: a let inside a case scrutinee is out of scope in the alternatives
grammar: typescript
asserts: types, values, stg

The binding `s` is local to the scrutinee. The alternative's `x`, `y` and `q`
must not resolve to it.

--- tql ---
data P = Mk Int Int;
fst p = case p of { Mk a b -> a };
pick p q = case (let { s = 5 } in Mk s 6) of { Mk x y -> x + 10 * y + 100 * fst q };
main = pure $ pick (Mk 1 2) (Mk 7 8);

--- source ---
class A {}

--- values ---
[765]

--- types ---
fst :: P -> Int
pick :: a -> P -> Int
main :: Node -> [Int]
