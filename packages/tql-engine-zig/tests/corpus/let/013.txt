title: nested `let` groups
grammar: typescript
asserts: types, values

The inner group closes at its own `}`, leaving the outer body to continue.

--- tql ---
main =
  let {
    outer = 10
  } in
    let {
      inner = outer + 5
    } in
      pure inner;

--- source ---
class A {}

--- values ---
[15]

--- types ---
main : Node -> [Int]
