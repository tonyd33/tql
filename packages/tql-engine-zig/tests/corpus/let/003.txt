title: bindings are order-independent
grammar: typescript
asserts: core, types, values

`first` refers to `second`, which is written after it. Declaration order has no
semantic effect, so this resolves.

--- tql ---
main =
  let {
    first = second + 1;
    second = 10;
  }
  in pure first;

--- source ---
class A {}

--- values ---
[11]

--- types ---
main :: Node -> [Int]

--- core ---
main =
  let second = 10 in
  let first = op[+] second 1 in
  pure first
