title: `let` inside a pipe stage
grammar: typescript
asserts: types, values

The group is evaluated once per input value from the left stage.

--- tql ---
main =
  children | is_kind :class_declaration
  | let { n = .name | arr text } in n;

--- source ---
class A {}
class B {}

--- values ---
["A", "B"]

--- types ---
main : Node -> [String]
