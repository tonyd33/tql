title: a `let` binding holds a filter value used as a pipe stage
grammar: typescript
asserts: core, types, values

`names` is bound to a filter, not to its results. Binding does not run it; the
pipe does.

--- tql ---
main =
  let { names = #name | arr text; }
  in children | of_kind :class_declaration | names;

--- source ---
class A {}
class B {}

--- values ---
["A", "B"]

--- types ---
main :: Node -> [String]

--- core ---
main =
  let names = kleisli field[name] (arr text) in
  kleisli (kleisli children (of_kind :class_declaration)) names
