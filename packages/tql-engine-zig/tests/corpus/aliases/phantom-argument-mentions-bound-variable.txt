title: a variable unified with an alias that mentions it only in a phantom argument
grammar: typescript
asserts: types, values

`Tagged x` is `Int`, so unifying `x`'s type with it solves that type to `Int`.

--- tql ---
type Tagged t = Int;

retag :: t -> Tagged t -> Int;
retag tag n = n;

f x = retag x x;

main = pure (f 1);

--- source ---
class A {}

--- types ---

f :: Int -> Int
main :: Kleisli List Node Int
entry :: Node -> [Int]
