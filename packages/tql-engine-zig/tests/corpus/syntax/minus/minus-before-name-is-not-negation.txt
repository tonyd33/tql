title: a prefix minus before a name is not negation
grammar: typescript
asserts: error

TQL has no `negate`, so `-x` is rejected rather than read as `x` applied to
nothing.

--- tql ---
x = 1;
main = Kleisli $ \_ -> [-x];

--- source ---
class A {}

--- error ---
error[parse]: TQL has no negation; write `0 - x`
