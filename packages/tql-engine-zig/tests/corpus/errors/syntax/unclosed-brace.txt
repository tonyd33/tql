title: an unclosed brace group
grammar: typescript
asserts: error

Group structure is delimited by braces alone, with no layout rule, so a missing
`}` is an ordinary parse error rather than a dedicated diagnostic.

The declaration is both unclosed and unterminated. Which of the two failures a
parser reports first is a recovery detail.

--- tql ---
main root = do {
  c <- children_of_kind :class_declaration root;
  return c

--- error ---
error[parse]: syntax error
 --> 1:1
  |
1 | main root = do {
  | ^^^^^^^^^^^^^^^^
2 |   c <- children_of_kind :class_declaration root;
  |   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
3 |   return c
  |   ^^^^^^^^
