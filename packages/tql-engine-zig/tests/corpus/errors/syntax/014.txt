title: an unclosed brace group
grammar: typescript

Group structure lost its rejection fixtures when the brace-only amendment
withdrew `ERR-LAYOUT-1` (STAGE-1.md §4.1). A missing `}` is now an ordinary
parse error, and this is the fixture that says so.

--- tql ---
main root =
  do {
    c <- (children | is_kind :class_declaration) root;
    c

--- error ---
category: parse
span: any
The declaration is both unclosed and unterminated, so the span covers all of
it rather than the `do` block alone. Which of the two failures a parser reports
first is a recovery detail.
