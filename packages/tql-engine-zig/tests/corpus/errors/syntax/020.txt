title: an undefined string escape is a parse error
grammar: typescript
asserts: error

Only `\"`, `\\`, `\n`, `\t` and `\r` are escapes. Any other is rejected
rather than kept as written.

--- tql ---
main = const ["a\qb"];

--- error ---
error[parse]: `\q` is not an escape; write `\\` for a backslash
