title: a module without a for clause cannot use kinds or fields
grammar: typescript
asserts: error

--- module Classes ---
module Classes;
classes root = descendants_of_kind :class_declaration root;
name n = n#name;

--- tql ---
import Classes;
main root = classes root | name;

--- error ---
error[grammar-mismatch]: this module has no `for` clause, so it cannot name the kind `class_declaration`
 --> Classes:2:36
  |
2 | classes root = descendants_of_kind :class_declaration root;
  |                                    ^^^^^^^^^^^^^^^^^^

error[grammar-mismatch]: this module has no `for` clause, so it cannot name the field `name`
 --> Classes:3:10
  |
3 | name n = n#name;
  |          ^^^^^^
