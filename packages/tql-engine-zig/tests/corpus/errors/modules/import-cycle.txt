title: an import cycle is rejected
grammar: typescript
asserts: error

`A` and `B` import each other. `C` imports itself, a cycle of length one.

--- module A ---
module A;
import B;
a = 1;

--- module B ---
module B;
import A;
b = 2;

--- module C ---
module C;
import C;
c = 3;

--- tql ---
import A;
import C;
main root = [a, c];

--- error ---
error[import-cycle]: imports form a cycle: `A` imports `B` imports `A`
 --> B:2:1
  |
2 | import A;
  | ^^^^^^^^^

error[import-cycle]: imports form a cycle: `C` imports `C`
 --> C:2:1
  |
2 | import C;
  | ^^^^^^^^^
