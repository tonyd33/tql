title: `main` bound to a projection is not a filter
grammar: typescript

`main` must be `Filter node output`. A projection is `node -> string`, which
is an ordinary function rather than a filter, so it does not unify with
`node -> [output]` for any `output`.

Before Q22 this fixture read `main = kind` and claimed a `Serial` failure. It
did not fail at all: `kind` was `Filter node string` and `main = kind` was the
eta-reduction of a correct program. Q22 made projections functions, which is
what this now tests — the failure is in `main`'s own type, not in `Serial`.

--- tql ---
main = kind;

--- error ---
category: main-type
span: 1:8-1:12
`main` must be `Filter node output`. Found `node -> string`; a projection
reaches filter position through `lift`.
