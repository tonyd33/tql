title: `main` bound to a projection is not a filter
grammar: typescript
asserts: error

`main` must be `Filter Node output`. `kind` is `Node -> Kind`, which
is an ordinary function rather than a filter, so it does not unify with
`Node -> [output]` for any `output`.

This fixture once claimed a `Serial` failure, back when `kind` was
`Filter Node String` and `main = kind` was the eta-reduction of a correct
program — so it did not fail at all. Projections are now functions, and the
failure is in `main`'s own type rather than in `Serial`.

A projection reaches filter position through `arr`.

--- tql ---
main = kind;

--- error ---
error[main-type]: Expected `[a]`, found `Kind`.
 --> 1:1
  |
1 | main = kind;
  | ^^^^^^^^^^^^
