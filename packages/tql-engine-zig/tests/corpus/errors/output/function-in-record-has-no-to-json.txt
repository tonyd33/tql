title: a filter nested in a record has no `ToJson`
grammar: typescript
asserts: error

`ToJson` fails recursively through a record.

--- tql ---
main = pure { name = "n", f = children };

--- error ---
error[unsatisfied-constraint]: `ToJson (Filter Node Node)` is not satisfied.
 --> 1:1
  |
1 | main = pure { name = "n", f = children };
  | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
