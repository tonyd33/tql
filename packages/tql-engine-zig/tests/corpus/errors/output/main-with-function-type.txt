title: `main` may not be a function
grammar: typescript
asserts: error

A query is a `Filter`, which is not a function. A parameter on the head makes
`main` a function from the root.

--- tql ---
main root = [root];

--- error ---
error[main-type]: Expected `Kleisli List Node a`, found `b -> [b]`.
 --> 1:1
  |
1 | main root = [root];
  | ^^^^^^^^^^^^^^^^^^^
