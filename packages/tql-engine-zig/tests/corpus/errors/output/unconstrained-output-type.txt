title: an unconstrained output type is an ambiguity error
grammar: typescript
asserts: error

`empty :: Filter a b` leaves `b` free. Nothing in the program fixes it, so no
`ToJson` instance can be selected.

--- tql ---
main = empty;

--- error ---
error[ambiguous-constraint]: `ToJson a` is ambiguous: nothing determines its type.

  |
1 | main = empty;
