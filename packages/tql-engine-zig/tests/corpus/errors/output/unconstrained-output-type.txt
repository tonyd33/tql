title: an unconstrained output type is an ambiguity error
grammar: typescript
asserts: error

`empty :: Filter a b` leaves `b` free. Nothing in the program fixes it, so no
`Serial` instance can be selected.

--- tql ---
main = empty;

--- error ---
error[ambiguous-output]: Expected `Node`, found `a`.
 --> 1:1
  |
1 | main = empty;
  | ^^^^^^^^^^^^^
