title: a stream-bound value may not escape its input type
grammar: typescript

`Gen(Gamma, a, b)` excludes variables free in the bind's input type. A
branch-local value cannot be polymorphic over the type of the input it came
from, so `c` cannot be used at two different types.

--- tql ---
main root =
  do {
    c <- (children | is_kind :class_declaration) root;
    collect { a = pure (kind c), b = length c }
  };

--- error ---
category: type-mismatch
span: 4:38-4:46
The second use of `c`. Expected `node`, found a use requiring `Sized`.
