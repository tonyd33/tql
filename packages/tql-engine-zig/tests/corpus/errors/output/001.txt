title: `main` must have type `Filter Node _`
grammar: typescript
asserts: error

`main` is applied to the parsed root, so its input type is `node`. A filter
over a different input type cannot be the entrypoint.

--- tql ---
main = identity;

--- error ---
error[main-type]: Expected `[a]`, found `Node`.
 --> 1:1
  |
1 | main = identity;
  | ^^^^^^^^^^^^^^^^
