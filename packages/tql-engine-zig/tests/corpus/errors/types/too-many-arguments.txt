title: applying too many arguments is a compile error
grammar: typescript
asserts: error

`inc` takes one argument. Applying two is not a runtime arity check; the
inferred type has no arrow left to consume the second argument, `2`.

--- tql ---
inc n = n + 1;
main = inc 1 2;

--- error ---
error[over-application]: `Int` has no argument left to take.
 --> 2:14
  |
2 | main = inc 1 2;
  |              ^
