title: unification does not bind a variable to a type of another kind
grammar: typescript
asserts: error

`f g` against `Box Int` would make `f` the `Box`, but `f` takes a constructor
and `Box` takes a type.

--- tql ---
import Data.Function (const);

data Box a = Box a;

p :: f g -> g Int -> Int;
p _ _ = 1;

main = const [p (Box 1) [1]];

--- error ---
error[type-mismatch]: Expected `a b`, found `Box Int`.

  |
8 | main = const [p (Box 1) [1]];
  |                  ^^^^^
