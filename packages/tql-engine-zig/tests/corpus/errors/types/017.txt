title: `Eq` on a list containing functions
grammar: typescript
asserts: error

A container holding a function is outside `Eq`, recursively.

`[kind, text]` is a list literal of two functions, so it is `[Node -> String]`.
Functions have no `Eq`, and the list inherits that.

--- tql ---
main =
  let {
    fs = [kind, text]
  } in
    fs = fs;

--- error ---
category: unsatisfied-constraint
span: 5:5-5:12
`Eq [Node -> String]` is not satisfied.
