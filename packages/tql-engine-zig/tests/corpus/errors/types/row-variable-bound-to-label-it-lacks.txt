title: a row variable is never bound to a label it lacks
grammar: typescript
asserts: error

`r` is the tail of rows with `a` and with `b`, so it lacks both (Types:
Records and rows).

--- tql ---
f :: {a: Int | r} -> {b: Int | r} -> Int;
f x y = x.a + y.b;
main = pure $ f {a = 1, b = "s"} {b = 3};

--- error ---
error[type-mismatch]: Expected `{a: Int}`, found `{a: Int, b: String}`. The expected record cannot have `b`.

  |
3 | main = pure $ f {a = 1, b = "s"} {b = 3};
