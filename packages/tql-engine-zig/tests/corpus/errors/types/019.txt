title: `Ord` on a node
grammar: typescript
asserts: error

`node` has `Eq` but not `Ord`, so ordering two nodes is rejected even though
comparing them for equality is not.

--- tql ---
main root = do {
  l <- children_of_kind :class_declaration root;
  r <- children_of_kind :class_declaration root;
  return $ l < r;
};

--- error ---
error[unsatisfied-constraint]: `Ord Node` is not satisfied.
 --> 4:12
  |
4 |   return $ l < r;
  |            ^^^^^
