title: `==` on a declared type that derives nothing
grammar: typescript
asserts: error

A declared type has no `Eq` unless it derives or writes one.

--- tql ---
import Data.Function (const);

data Shape = Circle Int;
main = Filter (const [Circle 1 == Circle 1]);

--- error ---
error[unsatisfied-constraint]: `Eq Shape` is not satisfied.
