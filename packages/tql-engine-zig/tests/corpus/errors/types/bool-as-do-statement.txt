title: `is_kind` is a test, not a `do` statement
grammar: typescript
asserts: error

`is_kind` returns a `Bool`, which is no monad's value. `guard $ is_kind :k c;`
is the statement form.

--- tql ---
main = do {
  c <- children;
  is_kind :class_declaration c;
  return c;
};

--- error ---
error[type-mismatch]: Expected `a b`, found `Bool`.
