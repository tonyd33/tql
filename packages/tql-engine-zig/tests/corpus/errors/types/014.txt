title: a node is not a condition
grammar: typescript
asserts: error

A non-empty navigation result is not implicitly true.

--- tql ---
main = if children | of_kind :class_declaration then pure "yes" else pure "no";

--- error ---
error[type-mismatch]: Expected `Bool`, found `Node -> [Node]`.
