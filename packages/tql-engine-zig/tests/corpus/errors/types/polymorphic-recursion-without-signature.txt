title: polymorphic recursion without a signature is rejected
grammar: typescript
asserts: error

`nest` calls itself at `[a]`. Without a signature the recursive call is at
the definition's own type, so `a` would have to equal `[a]`.

--- tql ---
nest n x = if n = 0 then 0 else 1 + nest (n - 1) [x];
main = always (nest 3 1);

--- error ---
error[type-mismatch]: Expected `a`, found `[a]`.
 --> 1:1
  |
1 | nest n x = if n = 0 then 0 else 1 + nest (n - 1) [x];
  | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
