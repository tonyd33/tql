title: a name bound by `<-` is not generalized
grammar: typescript
asserts: error

`f` cannot be used at two different types.

--- tql ---
pairs _ = do {
  f <- [\x -> x];
  return { a = f 1, b = f "s" };
};
main = Filter pairs;

--- error ---
error[type-mismatch]: Expected `Int`, found `String`.
 --> 3:27
  |
3 |   return { a = f 1, b = f "s" };
  |                           ^^^
