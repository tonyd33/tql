title: a constraint on main's input is checked at Node
grammar: typescript
asserts: error

`main` is run at `Node`, so its `Ord a` is `Ord Node`, which does not hold.

--- tql ---
main = arr (\x -> x < x);

--- error ---
error[unsatisfied-constraint]: `Ord Node` is not satisfied.

  |
