title: a row variable applied to a datatype lacks what the datatype's fields need
grammar: typescript
asserts: error

`W r` needs `r` to lack `x`, so `r` is never `{x: Int}` (Types: Records
and rows).

--- tql ---
data W r = W {x: Int | r};

f :: [W r] -> {y: Int | r} -> Int;
f _ _ = 0;

main = pure $ f [] {x = 2, y = 1};

--- source ---
class A {}

--- error ---
error[type-mismatch]: Expected `{y: Int | a}`, found `{x: Int, y: Int}`. The expected record cannot have `x`.
