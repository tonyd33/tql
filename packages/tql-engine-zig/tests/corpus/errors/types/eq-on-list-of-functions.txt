title: `Eq` on a list containing functions
grammar: typescript
asserts: error

A container holding a function is outside `Eq`, recursively.

`[kind_name, text]` is a list literal of two functions, so it is `[Node -> String]`.
Functions have no `Eq`, and the list inherits that.

--- tql ---
main =
  let { fs = [kind_name, text]; }
  in fs == fs;

--- error ---
error[unsatisfied-constraint]: `Eq (Node -> String)` is not satisfied.
 --> 3:6
  |
3 |   in fs == fs;
  |      ^^^^^^^^
