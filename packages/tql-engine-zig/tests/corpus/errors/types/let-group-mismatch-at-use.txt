title: a mismatch with another binding of the group is reported at the use
grammar: typescript
asserts: error

`b` refers to nothing else in the group, so it is checked first, and `a`'s use
of it is where the mismatch is found.

--- tql ---
main = let { a = b + 1; b = "s"; } in always a;

--- error ---
error[type-mismatch]: Expected `Int`, found `String`.

  |
