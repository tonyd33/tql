title: `Ord` on a type that derives only `Eq`
grammar: typescript
asserts: error

`T` derives `Eq`, so `=` on it type-checks, but nothing gives it `Ord`.

--- tql ---
data T = T deriving (Eq);
main = const [T = T, T < T];

--- error ---
error[unsatisfied-constraint]: `Ord T` is not satisfied.
