title: `Ord` on a list holds only when it holds for the elements
grammar: typescript
asserts: error

Lists order lexicographically, which needs an order on the elements. `Node`
has none.

--- tql ---
main root = do {
  l <- children_of_kind :class_declaration root;
  return $ [l] < [l];
};

category: unsatisfied-constraint
