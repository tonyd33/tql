title: a supertype kind is a compile error
grammar: python
asserts: error

No node has a supertype's kind, so `:expression_statement` would match
nothing. The diagnostic lists the subtypes to use instead.

--- tql ---
main = descendants_of_kind :expression_statement;

--- error ---
error[supertype-kind]: `expression_statement` is a supertype, so no node has this kind; use one of its subtypes: `assignment`, `augmented_assignment`, `expression`, `tuple_expression`, `yield`
