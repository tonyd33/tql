title: `Functor` cannot be derived for a type without a parameter
grammar: typescript
asserts: error

--- tql ---
data N = N Int deriving (Functor);
main = pure 1;

--- error ---
error[invalid-deriving]: `Functor` ranges over `N`'s last parameter, which it does not have
