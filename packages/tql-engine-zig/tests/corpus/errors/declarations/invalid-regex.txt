title: an invalid regex literal is a compile error
grammar: typescript
asserts: error

The pattern is compiled when the query is compiled, so an unclosed group fails
at compile time rather than producing a runtime branch failure.

--- tql ---
main = "abc" ~ r"(unclosed";

--- error ---
error[invalid-regex]: `(unclosed` is not a valid regular expression
 --> 1:16
  |
1 | main = "abc" ~ r"(unclosed";
  |                ^^^^^^^^^^^^
