title: deriving `Serial` on a type holding a function
grammar: typescript
asserts: error

A function has no JSON encoding, so `F` cannot derive `Serial`.

--- tql ---
data F = F (Int -> Int) deriving (Serial);
main = const [];

--- error ---
error[unsatisfied-constraint]: `Serial F` needs `Serial (Int -> Int)`
