title: deriving `Ord` without `Eq`
grammar: typescript
asserts: error

`Eq` is `Ord`'s superclass, so `Ord T` needs `Eq T`.

--- tql ---
import Data.Function (const);

data T = T Int deriving (Ord);
main = const [];

--- error ---
error[invalid-instance]: `Ord T` needs `Eq T`
