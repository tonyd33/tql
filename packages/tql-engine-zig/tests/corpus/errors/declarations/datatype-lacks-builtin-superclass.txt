title: an instance whose head lacks its class's superclass
grammar: typescript
asserts: error

`Op` derives no `Eq`, so `Same Op` cannot have the superclass its class asks
for.

--- tql ---
class Eq a => Same a where { same :: a -> a -> Bool; };
data Op = Op (Int -> Int);
instance Same Op where { same a b = True; };
main root = [1];

--- error ---
error[invalid-instance]: `Same Op` needs `Eq Op`
 --> 3:1
  |
3 | instance Same Op where { same a b = True; };
  | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
