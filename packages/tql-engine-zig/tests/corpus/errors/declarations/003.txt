title: a `do` binding is not visible after its block
grammar: typescript
asserts: error

The binding is branch-local to the block.

--- tql ---
main root = do {
  c <- children_of_kind :class_declaration root;
  n <- c.name;
  return $ text n;
};
after = c;

--- error ---
category: unresolved-name
span: 6:9-6:10
`c` in `after`.
