title: a row variable is not also a type
grammar: typescript
asserts: error

The variable after `|` stands for the rest of a record, not a type.

--- tql ---
import Data.Function (const);

f :: {name: String | r} -> r;
f x = x;
main = const [];

--- error ---
error[type-mismatch]: `r` stands for a record's other fields in one place and for a type in another
 --> 3:28
  |
3 | f :: {name: String | r} -> r;
  |                            ^
