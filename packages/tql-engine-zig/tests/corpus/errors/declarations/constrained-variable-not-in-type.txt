title: a context may constrain only a variable of the type
grammar: typescript
asserts: error

No use of `f` could fix `b`, so the constraint could never be decided.

--- tql ---
import Data.Function (const);

f :: Eq b => a -> a;
f x = x;
main = const [f 1];

--- error ---
error[unresolved-name]: `b` is constrained but does not appear in the type
