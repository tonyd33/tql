title: `Eq a` does not entail its subclass `Ord a`
grammar: typescript
asserts: error

`<` needs `Ord a`. `Ord` is a subclass of `Eq`, so `Ord a` entails `Eq a`,
never the reverse.

--- tql ---
import Data.Function (const);

less :: Eq a => a -> a -> Bool;
less x y = x < y;
main = const [less 1 2];

--- error ---
error[signature-mismatch]: `Ord a` is not satisfied.
 --> 3:1
  |
3 | less :: Eq a => a -> a -> Bool;
  | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
