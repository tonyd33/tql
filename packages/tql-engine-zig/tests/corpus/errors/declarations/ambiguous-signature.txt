title: a written context may constrain only a variable its type determines
grammar: typescript
asserts: error

No use could fix `b`: in `f` it is absent, in `g` the alias drops it, in `m`
only `a` is the class's, and the instance's head is `T a`.

--- tql ---
type Const a b = a;

f :: Eq b => a -> a;
f x = x;
g :: Eq b => Const Int b -> Int;
g x = x;
class C a where {
  m :: Eq b => a -> Int;
};
data T a = T a;
instance Eq b => Eq (T a) where {
  eq x y = True;
};
main = pure 1;
