title: an empty operand stream annihilates a lifted connective
grammar: typescript
asserts: types
pending: values

`and` is scalar, so reaching a stream operand goes through `do`. An empty bind
contributes nothing, which is where the annihilation lives now.

--- tql ---
main root =
  do {
    a <- (pure true, pure false) root;
    b <- (children | is_kind :interface_declaration | pure true) root;
    pure (a and b) root
  };
