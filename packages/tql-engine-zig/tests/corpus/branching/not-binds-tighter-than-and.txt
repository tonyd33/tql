title: `not p and q` groups as `(not p) and q`
grammar: typescript
asserts: core, types, values

`and` binds looser than `not`. If it grouped as `not (p and q)`, the result
would be `[true]`.

--- tql ---
main = pure $ not False and False;

--- source ---
class A {}

--- values ---
[false]

--- types ---
main :: Kleisli List Node Bool
entry :: Node -> [Json]

--- core ---
main = pure (and (not False) False)
entry = run_main main
