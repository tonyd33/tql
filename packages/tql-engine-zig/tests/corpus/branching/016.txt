title: `none` as a branch yields nothing for that input
grammar: typescript
asserts: core, types, values

`,` is union over filters, so each literal is written `pure n` to be one. The
composed filter is then applied to an ignored input.

--- tql ---
main =
   (pure 1, pure 2, pure 3) | branch (arr (\n -> n = 2)) (arr identity) none;
