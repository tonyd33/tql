title: `not` binds tighter than `and`, like any application
grammar: typescript
asserts: core, types, values

`not true and false` groups as `(not true) and false`.

--- tql ---
main = pure $ not true and false;

--- source ---
class A {}

--- values ---
[false]

--- types ---
main :: Node -> [Bool]

--- core ---
main = pure (and (not True) False)
