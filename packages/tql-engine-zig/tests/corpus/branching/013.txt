title: `not` over an application takes `$`
grammar: typescript
asserts: types, values

`not is_a "A" n` would be `((not is_a) "A") n`. `$` applies `not` to the whole
application.

--- tql ---
is_a expected n = text n = expected;

main =
  children | is_kind :class_declaration
  | .name
  | arr (\n -> not $ is_a "A" n);

--- source ---
class A {}
class B {}

--- values ---
[false, true]

--- types ---
is_a : String -> Node -> Bool
main : Node -> [Bool]
