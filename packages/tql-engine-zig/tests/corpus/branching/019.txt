title: a nested pattern matches a list of exactly two
grammar: typescript
asserts: core, types, values

`_` is reached from three paths, so its body is bound once and applied.

--- tql ---
pair xs = case xs of {
  Cons a (Cons b Nil) -> [a, b];
  _ -> [];
};

main = const [pair [1, 2], pair [1], pair [1, 2, 3]];

--- source ---
class A {}

--- values ---
[[1, 2], [], []]

--- core ---
pair = \xs -> letrec { alternative = Nil } in case xs of { Nil -> alternative; Cons a cons1 -> case cons1 of { Nil -> alternative; Cons b cons1 -> case cons1 of { Nil -> Cons a (Cons b Nil); Cons _ _ -> alternative } } }
main = const (Cons (pair (Cons 1 (Cons 2 Nil))) (Cons (pair (Cons 1 Nil)) (Cons (pair (Cons 1 (Cons 2 (Cons 3 Nil)))) Nil)))

--- types ---
pair :: [a] -> [a]
main :: Node -> [[Int]]
