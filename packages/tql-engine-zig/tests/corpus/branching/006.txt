title: a scalar connective maps over a stream with `lift`
grammar: typescript
asserts: types
pending: values

`not` is scalar, so negating each output of a stream is `lift` at the call site
rather than a property of `not` itself. `not` is an operator, not an
identifier, so the lifted function is written as a lambda.

--- tql ---
main = (pure true, pure false) | lift (\b -> not b);

--- source ---
class A {}

--- values ---
[false, true]

--- types ---
main : Node -> [Bool]
