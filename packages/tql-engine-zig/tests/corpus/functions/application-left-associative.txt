title: application is left-associative
grammar: typescript
asserts: core, types, values

`add 2 3` is `(add 2) 3`. The explicit grouping produces the same value, which
is what left-associativity means here.

--- tql ---
add x y = x + y;
main = Filter (\_ -> [add 2 3, (add 2) 3]);

--- source ---
class A {}

--- values ---
[5, 5]

--- types ---
add :: Int -> Int -> Int
main :: Filter Node Int

--- core ---
add = \x -> \y -> op[+] x y
main = Filter (\_ -> Cons (add 2 3) (Cons (add 2 3) Nil))
