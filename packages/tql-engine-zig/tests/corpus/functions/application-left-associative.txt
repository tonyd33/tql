title: application is left-associative
grammar: typescript
asserts: core, types, values

`add 2 3` is `(add 2) 3`. The explicit grouping produces the same value, which
is what left-associativity means here.

--- tql ---
import Data.Function (const);

add x y = x + y;
main = const [add 2 3, (add 2) 3];

--- source ---
class A {}

--- values ---
[5, 5]

--- types ---
add :: Int -> Int -> Int
main :: Node -> [Int]

--- core ---
add = \x -> \y -> op[+] x y
main = const (Cons (add 2 3) (Cons (add 2 3) Nil))
