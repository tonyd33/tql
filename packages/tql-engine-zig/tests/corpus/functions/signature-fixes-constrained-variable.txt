title: a signature may fix a constrained variable to a type that satisfies it
grammar: typescript
asserts: types, values

The body needs `Eq a`. The signature fixes `a` to `Int`, where it holds, so no
constraint is left for the signature to carry.

--- tql ---
same :: Int -> Int -> Bool;
same x y = x = y;
main = Filter (\_ -> [same 1 1, same 1 2]);

--- source ---
class A {}

--- values ---
[true, false]

--- types ---
same :: Int -> Int -> Bool
main :: Filter Node Bool
