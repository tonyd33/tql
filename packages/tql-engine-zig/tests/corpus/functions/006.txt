grammar: typescript

`\x y -> x + y` and `\x -> \y -> x + y` are the same value. Both are applied
the same way.

--- tql ---
main =
  let {
    a = \x y -> x + y;
    b = \x -> \y -> x + y
  } in
    a 1 2, b 1 2;
