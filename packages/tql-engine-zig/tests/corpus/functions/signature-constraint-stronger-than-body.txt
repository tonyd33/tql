title: a signature may require a constraint the body does not
grammar: typescript
asserts: types, values

A signature may be more specific than the body. The exported scheme carries
`Eq a`, so every use must satisfy it.

--- tql ---
same :: Eq a => a -> a;
same x = x;
main = pure (same 1);

--- source ---
class A {}

--- values ---
[1]

--- types ---
same :: Eq a => a -> a
main :: Filter Node Int
