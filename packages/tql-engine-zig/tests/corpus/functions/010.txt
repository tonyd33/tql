title: a filter returned from a function
grammar: typescript
asserts: types, values

`matcher` constructs a filter from a string. Ordinary application builds the
filter; the pipe executes it.

--- tql ---
matcher expected = #name | arr (\n -> text n = expected);
main = children | of_kind :class_declaration | matcher "A";

--- source ---
class A {}
class B {}

--- values ---
[true, false]

--- types ---
matcher :: String -> Node -> [Bool]
main :: Node -> [Bool]
