title: a constraint on a list is covered by one on its elements
grammar: typescript
asserts: types, values

Comparing two lists raises `Eq [a]`, which holds when `Eq a` does.

--- tql ---
same :: Eq a => [a] -> [a] -> Int;
same x y = if x == y then 1 else 0;
main = Filter (\_ -> [same [1] [1], same [1] [2]]);

--- source ---
class A {}

--- values ---
[1, 0]

--- types ---
same :: Eq a => [a] -> [a] -> Int
main :: Filter Node Int
