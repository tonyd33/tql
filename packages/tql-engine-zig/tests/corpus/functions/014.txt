title: forward references between globals are valid
grammar: typescript
asserts: core, types, values

`main` refers to `helper`, which is declared after it. Declaration heads are
collected before any body is resolved.

--- tql ---
main = pure $ helper 3;
helper n = n * 2;

--- source ---
class A {}

--- values ---
[6]

--- types ---
main :: Node -> [Int]
helper :: Int -> Int

--- core ---
main = pure (helper 3)
helper = \n -> op[*] n 2
