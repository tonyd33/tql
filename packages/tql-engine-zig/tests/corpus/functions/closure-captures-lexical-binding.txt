title: closures capture their lexical environment
grammar: typescript
asserts: types, values, stg

`bump` captures `step` from the enclosing group, not from its call site.

--- tql ---
main =
  let {
    step = 5 + 5;
    bump = \x -> x + step;
  }
  in Filter (\_ -> map bump [1, 2]);

--- source ---
class A {}

--- values ---
[11, 12]

--- types ---
main :: Filter Node Int

          Cons 1 t3@0
      in
      map[List] t1@2 t4@3
  in
  t5@1
