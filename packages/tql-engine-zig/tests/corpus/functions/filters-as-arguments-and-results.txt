title: a higher-order function taking and returning filters
grammar: typescript
asserts: types, values

`both` takes two filters and returns their union as a new filter. Both
arguments are `Filter Node String`, which is what lets the union unify.

--- tql ---
both f g = f <|> g;
main = children | of_kind :class_declaration | both (#name | arr text) (arr kind_name);

--- source ---
class A {}

--- values ---
["A", "class_declaration"]

--- types ---
both :: Alternative b => (a -> b c) -> (a -> b c) -> a -> b c
main :: Node -> [String]
