title: an over-application applies the result to the rest
grammar: typescript
asserts: values, stg

`adder` takes one parameter and returns a closure, so `adder 1 10` calls a
closure of arity one with two arguments.

--- tql ---
adder a = let { add b = a + b } in add;
main = pure $ adder 1 10;
