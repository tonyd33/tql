title: an over-application applies the result to the rest
grammar: typescript
asserts: values, stg

`adder` takes one parameter and returns a partial application, so
`adder 1 10` calls a function of arity one with two arguments.

--- tql ---
add a b = a + b;
adder a = add a;
main = pure $ adder 1 10;
