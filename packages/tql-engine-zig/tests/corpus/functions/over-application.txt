title: an over-application applies the result to the rest
grammar: typescript
asserts: values, stg

`adder` takes one parameter and returns a function, so `adder 1 10` calls a
function of arity one with two arguments. It is recursive, so the call is
not inlined.

--- tql ---
import Data.Function (compose, identity);

add a b = a + b;
adder n = if n = 0 then identity else compose (add 1) (adder (n - 1));
main = always $ adder 1 10;
