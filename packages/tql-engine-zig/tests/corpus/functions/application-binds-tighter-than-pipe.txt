title: application binds tighter than pipe
grammar: typescript

`children | of_kind :class_declaration` groups as
`children | (of_kind :class_declaration)`.

--- tql ---
main = children | of_kind :class_declaration | #name | arr text;

--- source ---
class A {}
class B {}

--- values ---
["A", "B"]

--- types ---
main :: Node -> [String]

--- core ---
main = kleisli (kleisli (kleisli children (of_kind :class_declaration)) field[name]) (arr text)
