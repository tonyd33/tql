title: signature variables are renamed in order of appearance in the type
grammar: typescript
asserts: types, values

`x` appears first in the type, so it prints as `a` even though the context
names `y` first. The context keeps the order it was written in.

--- tql ---
pick :: (Eq y, Ord x) => x -> y -> x;
pick x y = if y == y then (if x < x then x else x) else x;
main = pure (pick 1 "s");

--- source ---
class A {}

--- values ---
[1]

--- types ---
pick :: (Eq b, Ord a) => a -> b -> a
main :: Filter Node Int
