title: a filter passed as an argument
grammar: typescript

`apply_to_classes` takes a filter and runs it as a pipe stage. The argument is
already `Filter`-typed, so it is used directly rather than lifted.

--- tql ---
apply_to_classes f = children | is_kind :class_declaration | f;
main = apply_to_classes (.name | lift text);

--- source ---
class A {}
class B {}

--- values ---
["A", "B"]

--- types ---
apply_to_classes : (Node -> [a]) -> Node -> [a]
main : Node -> [String]
