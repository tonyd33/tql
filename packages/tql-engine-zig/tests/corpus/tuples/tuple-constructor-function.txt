title: `(,)` and `(,,)` are the tuple constructors as functions
grammar: typescript
asserts: types, values

--- tql ---
pairs = map ((,) 0) [1, 2];

main root = [((,,) 1 2 3, pairs)];

--- source ---
class A {}

--- values ---
[[[1,2,3],[[0,1],[0,2]]]]
--- types ---
pairs :: [(Int, Int)]
main :: Node -> [((Int, Int, Int), [(Int, Int)])]
